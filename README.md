# PID Hunter

A simple but powerful OBD-II diagnostic and PID discovery tool for ELM327 adapters.
PID Hunter is designed to brute-force manufacturer-specific PIDs, analyze ECU responses, and simplify reverse engineering of proprietary diagnostic protocols.

## ⚠️ This project is currently under active development.

## Features

* 🔍 Brute-force scanning for Mode 01, Mode 21 and Mode 22 PIDs
* 📡 Automatic ELM327 communication and protocol initialization
* 🔄 Resume interrupted scans
* 📊 Live scan statistics and ETA
* 📝 Real-time terminal with TX/RX logging
* 📁 CSV and JSON export
* 🧪 ECU connectivity testing
* 🔎 Supported diagnostic mode discovery
* 🛠 Configurable request delay and timeout
* 💙 Native SwiftUI interface for iPhone, iPad and macOS

⸻

## Requirements

* macOS / iOS
* Xcode 16+
* Bluetooth LE ELM327 adapter

⸻

## Current Status

The project is currently focused on:
